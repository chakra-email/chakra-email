# Chakra UI v2 Example

This example uses the legacy Chakra UI v2 adapter.

```bash
npm install @chakra-email/chakra-v2 react react-dom
```

See [legacy-theme-email.tsx](legacy-theme-email.tsx).

The repository-level `npm run examples:check` command compiles this source and
invokes its render function as part of the examples smoke suite.
